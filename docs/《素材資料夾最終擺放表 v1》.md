《素材資料夾最終擺放表 v1》
一、目標

這份表的目的，是讓 Codex 一眼就知道：

哪些是 整頁 UI 參考圖
哪些是 可切圖／可實作的 UI 素材
哪些是 Hero 主視覺圖
哪些素材屬於 Today / Star Bottle / Footprints / Common
後續前端開發時，圖片應該放在哪裡最清楚

三、各資料夾用途說明
1. docs/

放 規格文件 md 檔，不放圖片素材。

例如：

00-v1-source-of-truth.md
today-page-ui-spec-v1.md
star-bottle-page-ui-spec-v1.md
footprints-page-ui-spec-v1.md
our-page-ui-spec-v1.md
clear-page-ui-spec-v1.md
settings-page-ui-spec-v1.md
2. design/ui-reference/

放 整頁 UI 參考圖（Mockup / 視覺定稿圖）

這些圖主要是給您與 Codex 對照畫面長相，
不是直接切成小零件使用。

建議放入：
01-today.png
02-star-bottle.png
03-footprints.png
04-our.png
05-clear.png
06-settings.png
說明
這裡放的是「整頁長相」
Codex 用它來比對畫面佈局與風格
不建議直接當元件素材用
3. design/ui-assets/

放 設計素材原圖，也就是您剛剛做的各種小圖、Hero 圖、相框、星星等。

這裡是 設計資產母檔區。
可以理解成「素材倉庫」。

4. public/images/ui/

放 真正要給前端讀取使用的正式圖片

也就是當 Codex 寫 React / Vite / App UI 時，
實際會引用這裡的路徑，例如：

<img src="/images/ui/today/today-hero-couple-garden-cat-v1.png" />
重點
design/ui-assets/ = 設計整理區
public/images/ui/ = 程式正式使用區

您可以先把圖片放在 design/ui-assets/ 整理好，
等晚點要正式串接時，再複製一份到 public/images/ui/。
