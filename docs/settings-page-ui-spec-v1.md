# 《設定 UI 定稿規格 v1》

版本：v1.0  
用途：作為《星星戀愛日記》V1「設定」頁的正式 UI/UX、互動、資料管理與 Codex 開發基準。  
建議放置：`docs/settings-page-ui-spec-v1.md`

> 本規格以已確認的完整手機設定頁模擬圖為視覺基準。

---

# 1. 頁面定位

「設定」頁是《星星戀愛日記》的次級管理頁面。

核心任務：

> **讓使用者清楚知道：哪些資料可以修改、哪些內容可以管理、哪些權限與備份可以控制。**

此頁不是主內容頁，所以不需要大型角色插畫，也不需要底部五大導覽。

主要原則：

- 清楚
- 好找
- 好修改
- 不擁擠
- 不讓使用者因設定頁而感到壓力

---

# 2. 視覺風格

正式定稿如下：

- 奶油白背景
- 淡粉、淡藍、淡紫、淡黃 icon 點綴
- 大圓角卡片
- 柔和陰影
- 花朵、星星、蝴蝶結只作輕量裝飾
- 不放大型男女主角插畫
- 不做深色後台介面
- 不做商業帳號中心感
- 不做複雜分頁

整體感受：

> **像一本乾淨、溫柔、很好管理的戀愛手帳設定頁。**

# 7. 照片與回憶

功能：

- 查看全部
- 新增
- 刪除
- 重排

- 管理全部最多 60 張照片

---

## 7.2 我們的時刻

點擊後進入完整管理頁。

功能：

- 新增
- 編輯

- 排序

---

## 7.3 想對你說

點擊後進入編輯頁。

規則：

- 僅 1 張

- 可清除

V1 可在照片管理中納入：

- 已完成顯影照片

不強迫自動加入。

## 8.3 備份

V1 正式規則：

> **備份包含文字與結構資料，不包含照片。**

備份內容：

- 使用者資料
- 對方資料
- 關係日期
- 日記
- 星星
- 清醒紀錄
- 我記得的你
- 我們的時刻

- 設定

不包含：

- 原始照片
- 回憶牆照片檔
- 日記照片檔

設定頁需明確顯示：

> 備份僅包含文字，不含照片

- 紅色／警示色僅用於此類危險操作
- 二次確認
- 建議要求再次輸入確認文字或長按確認

# 24. 頁面核心設計原則

設定頁不需要可愛到搶戲。

它真正要做到的是：

> **使用者知道資料在哪裡、知道怎麼改、也知道怎麼保護自己的內容。**

這一頁應帶來：

- 安全感
- 清楚感
- 掌控感
- 乾淨感

而不是：

- 功能迷宮
- 商業中心感
- 帳號後台感

---

# 25. 最終定稿結論

《星星戀愛日記》設定頁正式由以下 8 個主要區域構成：

1. **基本資料**
2. **重要日子**
3. **照片與回憶**
4. **日記與星星**
5. **清醒**
6. **通知**
7. **語言**
8. **隱私與資料＋關於**

整個頁面的最終感受：

> **簡單、清楚，而且所有重要資料都在自己的掌握裡。**
