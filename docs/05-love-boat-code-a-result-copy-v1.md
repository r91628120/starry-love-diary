# 星星戀愛日記｜暈船法典 V1
## A 層結果文案庫：我暈多深？

版本：V1 Draft
用途：Milestone 4B－暈船法典
定位：自我覺察工具，不是心理診斷，不使用 AI，不判定使用者「有問題」。

---

## 1. A 層目的

A 層只回答一件事：

> **最近，我有多少注意力與情緒正在繞著這個人運轉？**

A 層不判斷：
- 對方是不是喜歡我
- 對方是不是適合我
- 這段關係好不好
- 我是不是「戀愛腦」
- 我是不是愛錯人

A 層只整理「我的投入與被牽動程度」。

---

## 2. 題目與計分

共 12 題。

每題選項：

- `0` 幾乎沒有
- `1` 偶爾
- `2` 有時
- `3` 常常

總分範圍：`0–36`

### A01
我會反覆查看他有沒有回我的訊息。

### A02
他很久沒有回覆時，我會很難專心做自己的事。

### A03
他一回我訊息，我的心情就會立刻變好很多。

### A04
我常常在腦中重播我們聊過的話或相處的畫面。

### A05
我會一直猜他的一句話、一個表情符號，甚至一個已讀到底代表什麼。

### A06
我會忍不住去看他的社群、動態或上線狀態。

### A07
我常常想確認他到底在不在乎我、喜不喜歡我。

### A08
他稍微冷淡一點，我就容易懷疑是不是自己做錯了什麼。

### A09
我曾為了等他的訊息、電話或回應，延後自己原本要做的事情。

### A10
我們實際還沒有走到那麼遠，但我已經常常在腦中想像很久以後的我們。

### A11
即使沒有新的事情發生，我腦中還是會一直想到他。

### A12
最近這個人或這段關係，佔了我很多注意力和心情。

---

## 3. A 層分級

| stable key | 分數 | 顯示名稱 |
|---|---:|---|
| `investment_low` | 0–8 | 心還在自己身上 |
| `investment_mild` | 9–17 | 開始有點被牽動 |
| `investment_high` | 18–26 | 注意力常常繞著對方 |
| `investment_very_high` | 27–36 | 這段關係最近佔了你很多心力 |

> 注意：以上名稱為產品中的覺察層級，不是心理學診斷或臨床分級。

# 4. 結果文案池

## Level 1｜`investment_low`
### 心還在自己身上

### `investment_low_01`
你有在意這個人，但目前看來，你仍然保留著自己的生活節奏。喜歡一個人，不一定要讓所有注意力都圍著他轉；現在的你，還能把不少心放在自己身上。

### `investment_low_02`
這段關係會讓你心動，但還沒有佔據你太多生活。你似乎仍然能做自己的事、過自己的日子，也允許關係慢慢發生。

### `investment_low_03`
你對他的在意目前比較像生活裡的一部分，而不是生活的全部。這種距離感讓你有空間喜歡對方，也有空間照顧自己。

### `investment_low_04`
你有感情，也有自己的步調。現在的你似乎不需要一直從對方的訊息或反應確認自己的心情，這讓你還能自在地待在自己的生活裡。

### `investment_low_05`
你的心有靠近他，但沒有因此離開自己太遠。可以繼續觀察這段關係，也繼續保留那些原本就屬於你的日常。

---

## Level 2｜`investment_mild`
### 開始有點被牽動

### `investment_mild_01`
你開始比以前更在意他的訊息、態度或反應了。這很常出現在喜歡一個人的時候，只是偶爾可以看看：今天的心情，有多少是由自己決定的？

### `investment_mild_02`
你的注意力已經慢慢往這段關係靠近。有時會想他、有時會猜他的意思，但目前還沒有完全佔據你的生活。讓關係發展的同時，也別忘了保留自己的節奏。

### `investment_mild_03`
你似乎開始期待更多，也因此比較容易受到互動影響。這不代表你投入得太多，只是可以提醒自己：除了等待對方的回應，今天還有哪些事情也值得你的注意？

### `investment_mild_04`
這個人已經開始進入你的日常心情裡了。有些期待很甜，有些等待也可能讓人不安。你可以喜歡他，同時慢慢練習不要把每一次情緒起伏都交給這段關係。

### `investment_mild_05`
你的心正在靠近他，也開始比較容易被他的反應牽動。不用急著把心收回來，只要記得偶爾回頭看看自己還在不在。

---

## Level 3｜`investment_high`
### 注意力常常繞著對方

### `investment_high_01`
最近你的注意力有不少正在繞著這個人運轉。訊息、態度、社群或一些小小的互動，都可能讓你想很久。也許現在可以試著把一部分心力，慢慢帶回自己的生活。

### `investment_high_02`
你真的很在意這段關係，也因此比較容易反覆想、等待、猜測。喜歡本身沒有問題，值得留意的是：你的生活是不是開始需要配合他的每一次反應？

### `investment_high_03`
你的心已經走得很靠近他了。有些期待會讓人開心，但當注意力長時間停在對方身上，也可能讓自己有點累。今天可以試著問自己：除了他，我還想把心放在哪裡？

### `investment_high_04`
這段關係最近佔了你不少心理空間。你可能會反覆想起互動、注意他的動態，或因為他的態度而改變心情。你不需要停止喜歡，只需要留一點位置給自己。

### `investment_high_05`
你現在投入得很深，許多小細節都會被你放在心上。當心一直往對方那邊跑時，可以偶爾提醒自己：關係可以慢慢走，而我的生活也值得繼續往前。

---

## Level 4｜`investment_very_high`
### 這段關係最近佔了你很多心力

### `investment_very_high_01`
這段關係最近真的佔了你很多注意力。你可能常常想到他，也很容易被訊息、互動或態度牽動。這不代表你的喜歡有問題，只是現在有很多心力正在繞著對方運轉。

### `investment_very_high_02`
你的心似乎已經投入得很深了。等待、猜測、想像和反覆回想，都可能讓這個人在你的生活裡變得非常巨大。喜歡可以很深，但不用因此把全部的自己都交出去。

### `investment_very_high_03`
最近你可能很難真正把這段關係放到一旁。即使沒有新的事情發生，心還是會不自覺回到他身上。現在最重要的不是逼自己不要想，而是慢慢把一些注意力帶回自己的生活。

### `investment_very_high_04`
你對他的在意已經影響到很多情緒與注意力。這份喜歡也許很真，但當一個人的反應開始決定你一天的大部分心情時，可以提醒自己：我的世界不只剩下這段關係。

### `investment_very_high_05`
你的心現在離他很近，也可能離自己稍微遠了一點。你不需要立刻抽離，更不用責怪自己。只是可以開始練習：喜歡他的同時，也把一部分心留給自己。

# 5. 文案輪替規則

V1 不使用 AI。

同一個 A 層結果提供多組預寫文案，由 App 本機輪替顯示。

建議規則：

1. 每個層級維護 5 組文案。
2. 優先顯示該使用者尚未看過的版本。
3. 5 組全部看過後，再從第 1 組開始循環。
4. 不建議單純 random，避免連續兩次顯示相同結果。
5. 顯示過哪一組，只需記錄 stable key 或 index。
6. 文案輪替不改變分數、不影響星心值。
7. 重做測驗時，如果分級改變，直接切換到新分級的文案池。

示意：

```ts
type InvestmentLevel =
  | "investment_low"
  | "investment_mild"
  | "investment_high"
  | "investment_very_high"

type ResultCopyState = {
  resultKey: InvestmentLevel
  lastVariantIndex: number
}
```

# 6. 與上一次測驗的比較

此功能可以完全使用本機規則，不需要 AI。

例如：

- A 分數明顯下降：
  > 和上一次相比，你似乎慢慢把一些注意力帶回自己身上了。

- A 分數明顯上升：
  > 和上一次相比，這段關係最近似乎佔了你更多心力。

- A 分數變化很小：
  > 和上一次相比，你目前投入這段關係的程度沒有太大變化。

### 建議 V1 門檻

- 差值 `≤ -4`：明顯下降
- 差值 `-3 ～ +3`：大致持平
- 差值 `≥ +4`：明顯上升

比較文案只描述變化，不評價好壞。

# 7. 語氣規範

所有 A 層文案必須：

- 不使用「嚴重」
- 不使用「正常／不正常」
- 不使用「病態」
- 不使用「戀愛腦太重」
- 不責怪使用者
- 不要求立即放棄關係
- 不判斷對方
- 不提供醫療或心理診斷
- 不宣稱量表具有臨床效度
- 強調「看見自己」而非「糾正自己」

建議核心語氣：

> **喜歡沒有錯，只是別在喜歡他的時候，把自己弄丟了。**

---

# 8. V1 實作原則

- Local First
- 不呼叫 OpenAI API
- 不呼叫其他 AI API
- 不生成 AI 結果
- 所有結果使用預寫 i18n 文案
- stable key 儲存於資料層
- 顯示文字由 locale 決定
- 不把中文文案直接當 enum
- 測驗可重做
- 每次測驗保留日期與分數，供後續趨勢比較
- 測驗本身不直接增加星心值
- 是否可存成「清醒星星」，待 B 層與完整 A+B 結果規則確定後再正式決定
